THE VEIL STORE — OWNER GALLERY

This gallery is intentionally NOT a public upload form.

To publish photographs on the website:
1. Add your image files to this folder.
2. Replace the gallery placeholder blocks in index.html with <img> elements pointing to your files, or ask for the gallery to be updated.
3. Commit/push the changes to GitHub Pages.

This keeps visitor uploads off the public website. GitHub Pages is static hosting, so it does not provide a secure private owner-only upload database by itself.
