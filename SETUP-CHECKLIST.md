# Setup checklist

[ ] Replace `public/assets/logo-placeholder.svg` with your logo
[ ] Confirm tagline in `config.json`
[ ] Replace sample product data/images in `data/products.json`
[ ] Replace priority-delivery pincodes in `config.json`
[ ] Set `RAZORPAY_KEY_ID` and `RAZORPAY_KEY_SECRET` in `.env`
[ ] Set `RAZORPAY_WEBHOOK_SECRET`
[ ] Run `npm install`
[ ] Run `npm start`
[ ] Test a full order in Razorpay Test Mode
[ ] Deploy backend with HTTPS
[ ] Add Razorpay webhook URL
[ ] Switch to Live Mode only after successful testing
